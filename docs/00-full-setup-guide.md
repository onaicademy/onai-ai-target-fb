## Шаг 1: Регистрация в Claude

Claude — это AI, который будет управлять рекламой. Нужна платная подписка.

1. Открой https://claude.ai
2. Нажми **Sign up**
3. Зарегистрируйся через Google или email
4. После регистрации нажми на иконку профиля → **Settings** → **Subscription**
5. Выбери план **Pro** ($20/месяц) или **Max** ($100/месяц)
6. Оплати картой

**Готово:** У тебя есть аккаунт Claude с подпиской.

## Шаг 2: Установка VS Code

VS Code — бесплатный редактор кода, в котором будет работать агент.

### Mac

1. Открой https://code.visualstudio.com
2. Нажми большую синюю кнопку **Download for Mac**
3. Скачается файл `VSCode-darwin-xxx.zip`
4. Открой папку Загрузки
5. Дважды кликни на скачанный файл — он распакуется
6. Перетащи **Visual Studio Code** в папку **Программы** (Applications)
7. Открой VS Code из папки Программы

### Windows

1. Открой https://code.visualstudio.com
2. Нажми **Download for Windows**
3. Запусти скачанный файл `VSCodeUserSetup-xxx.exe`
4. Нажимай **Далее** → **Далее** → **Установить**
5. После установки VS Code откроется автоматически

**Готово:** VS Code установлен.

## Шаг 7: Установка Python и uv

MCP сервер написан на Python. Нужно установить Python и менеджер пакетов uv.

### Mac

1. Открой программу **Terminal** (найди через Spotlight: `Cmd+Space`, введи "Terminal")

2. Установи Homebrew (менеджер программ). Скопируй и вставь в терминал:
   ```
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```
   Нажми Enter. Введи пароль от Mac если попросит. Подожди 5-10 минут.

3. После установки Homebrew, установи Python:
   ```
   brew install python@3.11
   ```

4. Установи uv:
   ```
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```

5. Перезапусти терминал (закрой и открой заново)

6. Проверь что всё работает:
   ```
   python3 --version
   uv --version
   ```
   Должны показать версии (например `Python 3.11.x` и `uv 0.x.x`)

### Windows

1. Скачай Python: https://www.python.org/downloads/
2. Запусти установщик
3. **ВАЖНО:** Поставь галочку **"Add Python to PATH"** внизу окна!
4. Нажми **Install Now**
5. Открой **PowerShell** (найди в меню Пуск)
6. Установи uv:
   ```
   pip install uv
   ```
7. Проверь:
   ```
   python --version
   uv --version
   ```

**Готово:** Python и uv установлены.

## Шаг 8: Получение Gemini API ключа

Gemini — это AI от Google для генерации креативов (картинок). Нужен API ключ.

### Часть 1: Создание проекта в Google Cloud

1. Открой https://console.cloud.google.com
2. Войди через свой Google аккаунт
3. Если появится окно "Условия использования" — прими их
4. Вверху слева нажми на выпадающий список проектов (рядом с "Google Cloud")
5. В открывшемся окне нажми **Новый проект** (New Project)
6. Заполни:
   - **Название проекта**: `ads-agent` (или любое)
   - **Организация**: оставь как есть или выбери "Нет организации"
7. Нажми **Создать** (Create)
8. Подожди 30 секунд — проект создаётся

### Часть 2: Создание API ключа

9. После создания проекта убедись что он выбран (название вверху слева)
10. В левом меню нажми **APIs & Services** (API и сервисы)
11. Слева выбери вкладку **Credentials** (Учётные данные)
12. Вверху нажми **+ Create Credentials** (Создать учётные данные)
13. Выбери **API Key** (Ключ API)
14. Появится окно с твоим ключом — он начинается с `AIza...`
15. Нажми **Copy** (Копировать) и сохрани ключ в надёжное место
16. Нажми **Close** (Закрыть)

### Часть 3: Ограничение ключа

17. В списке ключей найди только что созданный ключ
18. Нажми на него (на название или иконку редактирования)
19. Прокрути вниз до раздела **API restrictions** (Ограничения API)
20. Выбери **Restrict key** (Ограничить ключ)
21. В выпадающем списке выбери **Generative Language API**
22. Нажми **Save** (Сохранить)

### Часть 4: Активация ключа в AI Studio

23. Открой https://aistudio.google.com
24. Войди тем же Google аккаунтом
25. Слева нажми **Get API key**
26. Ты увидишь свой проект и созданный ключ
27. Нажми на ключ или на **Set up billing** (Настроить оплату)
28. Добавь банковскую карту для активации
29. После привязки карты ключ станет активным

**ВАЖНО:** Без привязки карты ключ не будет работать! Google не списывает деньги сразу — есть бесплатный лимит. Карта нужна для верификации.

**Сохрани ключ** — он понадобится на шаге 12 (настройка MCP).

**Готово:** У тебя есть активный Gemini API ключ.

## Шаг 9: Создание приложения в Meta

Приложение Meta — это "ключ" для доступа к рекламным аккаунтам через API.

1. Открой https://developers.facebook.com
2. Войди через свой Facebook аккаунт
3. Нажми **My Apps** (справа вверху)
4. Нажми **Create App**
5. Выбери **Other** → **Next**
6. Выбери **Business** → **Next**
7. Заполни:
   - **App name**: `My Ads Agent` (или любое название)
   - **App contact email**: твой email
   - **Business Account**: выбери свой Business Manager (или создай новый)
8. Нажми **Create App**
9. Введи пароль от Facebook

**Теперь добавим Marketing API:**

10. В левом меню найди **Add Product**
11. Найди **Marketing API** и нажми **Set Up**
12. Готово — Marketing API добавлен

**Запиши данные приложения:**

13. В левом меню нажми **App settings** → **Basic**
14. Скопируй и сохрани:
    - **App ID**: например `123456789012345`
    - **App Secret**: нажми "Show", скопируй (например `abc123def456...`)

**Готово:** Приложение создано.

## Шаг 10: Создание System User

System User — это "технический пользователь" для автоматизации. Его токен не истекает.

1. Открой https://business.facebook.com
2. Убедись что выбран нужный Business Manager (название вверху)
3. Нажми **шестерёнку** (Settings) слева внизу
4. В меню слева выбери **Users** → **System users**
5. Нажми **Add**
6. Заполни:
   - **System user name**: `ads-agent` (или любое)
   - **System user role**: **Admin**
7. Нажми **Create system user**

**Теперь добавим System User в приложение:**

8. Нажми на созданного system user
9. Нажми **Add Assets**
10. Выбери вкладку **Apps**
11. Найди своё приложение (`My Ads Agent`)
12. Включи переключатель
13. Выбери **Full control**
14. Нажми **Save Changes**

**Теперь дадим доступ к рекламным аккаунтам:**

15. Снова нажми **Add Assets**
16. Выбери вкладку **Ad Accounts**
17. Выбери все рекламные аккаунты, которыми хочешь управлять
18. Для каждого выбери **Full control**
19. Нажми **Save Changes**

**Дадим доступ к страницам (Pages):**

20. Нажми **Add Assets**
21. Выбери вкладку **Pages**
22. Выбери страницы, связанные с рекламой
23. Для каждой выбери **Full control**
24. Нажми **Save Changes**

**Готово:** System User создан и имеет доступ.

## Шаг 11: Получение Access Token

Access Token — это "пароль" для API. У System User он бессрочный.

1. Ты должен быть на странице System User (Business Settings → System users)
2. Нажми на своего system user (`ads-agent`)
3. Нажми кнопку **Generate new token**
4. Выбери своё приложение (`My Ads Agent`)
5. Отметь разрешения (permissions):
   - ✅ `ads_management`
   - ✅ `ads_read`
   - ✅ `pages_read_engagement`
   - ✅ `pages_manage_ads`
   - ✅ `business_management`
6. Нажми **Generate token**
7. Скопируй токен — он начинается с `EAAG...`

**ВАЖНО:**
- Токен покажут только один раз! Сохрани его в надёжное место.
- Никому не показывай токен — это как пароль от рекламы.

**Готово:** У тебя есть Access Token.

## Шаг 12: Настройка MCP сервера

Теперь соединим всё вместе.

1. Открой VS Code
2. Нажми **File** → **Open Folder**
3. Выбери папку `onai-ai-target-fb`
4. В VS Code слева увидишь файлы проекта

**Создай файл настроек MCP:**

5. Нажми правой кнопкой на пустое место в списке файлов
6. Выбери **New File**
7. Назови файл: `.mcp.json` (с точкой в начале!)
8. Вставь в файл этот код:

```json
{
  "mcpServers": {
    "meta-ads": {
      "command": "uv",
      "args": ["run", "--directory", "ПУТЬ_К_MCP", "meta-ads-mcp"],
      "env": {
        "META_APP_ID": "ТВОЙ_APP_ID",
        "META_APP_SECRET": "ТВОЙ_APP_SECRET",
        "META_ACCESS_TOKEN": "ТВОЙ_ACCESS_TOKEN",
        "GEMINI_API_KEY": "ТВОЙ_GEMINI_KEY"
      }
    }
  }
}
```

9. Замени значения:
   - `ПУТЬ_К_MCP` → полный путь к папке onai-ai-target-fb-mcp
     - Mac пример: `/Users/ivan/Projects/onai-ai-target-fb-mcp`
     - Windows пример: `C:\\Users\\ivan\\Projects\\onai-ai-target-fb-mcp` (двойные слеши!)
   - `ТВОЙ_APP_ID` → App ID из шага 9
   - `ТВОЙ_APP_SECRET` → App Secret из шага 9
   - `ТВОЙ_ACCESS_TOKEN` → токен из шага 11
   - `ТВОЙ_GEMINI_KEY` → Gemini API ключ из шага 8

10. Сохрани файл: `Cmd+S` (Mac) или `Ctrl+S` (Windows)

**Установи зависимости MCP:**

11. Открой терминал в VS Code: **Terminal** → **New Terminal**
12. Перейди в папку MCP:
    ```
    cd ПУТЬ_К_MCP
    ```
    (замени ПУТЬ_К_MCP на реальный путь)
13. Установи зависимости:
    ```
    uv sync
    ```
    Подожди пока скачаются все пакеты.

**Готово:** MCP сервер настроен.

## Шаг 13: Добавление рекламного аккаунта

Теперь добавим твой рекламный аккаунт в конфигурацию агента.

1. В VS Code открой файл `config/ad_accounts.md`

2. Тебе нужно найти ID своего аккаунта:
   - Открой https://adsmanager.facebook.com
   - Посмотри в адресную строку: `...?act=123456789`
   - Это твой Account ID. Добавь префикс: `act_123456789`

3. Найди Page ID:
   - Открой свою Facebook страницу
   - Нажми **О странице** → **Прозрачность страницы**
   - Там будет **Page ID**

4. Заполни файл `config/ad_accounts.md`:

```markdown
## Аккаунт 1: МойБизнес

- **Account ID**: act_123456789
- **Page ID**: 987654321
- **Instagram ID**: нет
- **Название**: Мой Бизнес
- **Сайт**: https://example.com
- **Бриф**: [briefs/mybusiness.md](briefs/mybusiness.md)
- **Статус**: активен
- **Валюта**: USD
- **Часовой пояс**: UTC+3 (Москва)
- **Тип конверсии**: Lead-формы
- **Заметки**: Описание бизнеса
```

5. Создай бриф:
   - Скопируй файл `config/briefs/_template.md`
   - Переименуй копию в `mybusiness.md`
   - Заполни целевой CPL, бюджеты и другую информацию

6. Сохрани все файлы

**Готово:** Аккаунт добавлен.

## Частые проблемы

### "MCP server not found"

- Проверь путь в `.mcp.json` — он должен быть полным и правильным
- На Windows используй двойные слеши: `C:\\Users\\...`
- Проверь что выполнил `uv sync` в папке MCP

### "Invalid access token"

- Токен скопирован неправильно — скопируй заново
- Токен не имеет нужных разрешений — сгенерируй новый с правильными permissions

### "Permission denied" на аккаунт

- System User не имеет доступа к аккаунту
- Вернись в Business Settings → System users → Add Assets → добавь аккаунт

### Ничего не происходит

- Перезапусти VS Code
- Проверь что расширение Claude Code установлено и авторизовано
