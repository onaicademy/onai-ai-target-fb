# Setup Checklist — подключение к рекламным кабинетам

## Когда вызывать

Этот скилл активируется когда пользователь:
- Только что установил агента и не знает с чего начать
- Спрашивает «что мне нужно сделать перед запуском рекламы»
- Просит «проверь, всё ли у меня настроено»
- Получил ошибку «нет рекламных аккаунтов» после `/mcp` авторизации в Pipeboard

## Как ведёшь диалог

Не вываливай весь чеклист сразу. Веди **по одному пункту**, дожидаясь ответа пользователя. Это интервью, не лекция.

Структура каждого шага:

1. **Спроси «есть ли у тебя X?»** — yes/no вопрос
2. **Если «нет»** — дай 3-4 строки что это и зачем + ссылка на официальный Meta Business Help + предложи ещё после настройки нажать «продолжить»
3. **Если «да»** — короткое подтверждение, переходишь к следующему пункту
4. **Не пытайся настраивать сам** — Meta API не даёт прав на создание BM, страниц, способов оплаты. Ты только помогаешь, делает пользователь руками.

## 7 пунктов проверки

### Пункт 1. Личный Facebook-аккаунт

Спроси:
> У тебя есть личный Facebook-аккаунт на твоё настоящее имя?

Если нет — отправь на facebook.com и предупреди: **не покупай старые аккаунты, fake-аккаунты Facebook банит**, особенно если к ним подключают рекламу.

### Пункт 2. Business Manager (BM)

Спроси:
> Создан ли у тебя Business Manager?

Если нет:
- Это «контейнер» для всех твоих страниц, рекламных аккаунтов, доступов
- Идти на: `business.facebook.com` → войти → создать новый BM
- Указать реальное имя бизнеса (менять сложно)
- **Включить 2FA на Facebook** — без этого BM могут угнать
- Гайд: https://www.facebook.com/business/help/1710077379203657

### Пункт 3. Бизнес-страница (Page) в BM

Спроси:
> У тебя есть бизнес-страница в Facebook? Она привязана к BM?

Если нет:
- Реклама показывается **от лица страницы**, не от твоего личного аккаунта
- В BM → «Страницы» → создать новую или добавить существующую
- Категорию выбирай реалистичную (Local Business / Brand / Service)
- Аватар + обложка обязательно — без них модерация рекламы хуже
- Гайд: https://www.facebook.com/business/help/104002523024878

### Пункт 4. Рекламный аккаунт (Ad Account) в BM

Спроси:
> В BM создан рекламный аккаунт? Знаешь ли его ID (вида `act_XXXXXXXXX`)?

Если нет:
- Это «кошелёк» для рекламы — к нему привязана оплата, в нём живут все кампании
- В BM → «Аккаунты» → «Рекламные аккаунты» → создать
- **ВАЖНО:** валюту и часовой пояс выбирай сразу правильно — менять потом нельзя, только пересоздавать
- Часовой пояс — твой реальный (`Asia/Almaty` если Алматы)
- Гайд: https://www.facebook.com/business/help/910137316041095

### Пункт 5. Instagram → Page (опционально)

Спроси:
> Будешь показывать рекламу в Instagram (Stories, Reels, Feed)?
> Если да — привязан ли твой Instagram-аккаунт к Facebook Page?

Если будет реклама в IG, но не привязан:
- Instagram должен быть в режиме **Business** или **Creator** (не Personal)
- В BM → «Аккаунты Instagram» → «Добавить» → логин/пароль IG → подтвердить связь с Page
- 2FA на Instagram временно отключи — иначе процесс ломается
- Гайд: https://www.facebook.com/business/help/377680519582516

Если рекламы в IG не будет — пропусти.

### Пункт 6. WhatsApp → Page (опционально)

Спроси:
> Будешь запускать рекламу с CTA «Send WhatsApp Message»?
> Если да — привязан ли WhatsApp Business к твоей Page?

Если будет, но не привязан:
- На телефоне должен быть установлен **WhatsApp Business** (не обычный WhatsApp)
- В Page → Настройки → WhatsApp → ввести номер → подтвердить SMS
- Один номер = один аккаунт. Если уже подключён к чужой Page — отвяжи там
- Гайд: https://www.facebook.com/business/help/2087193751603668

Если WhatsApp-реклама не нужна — пропусти.

### Пункт 7. ⚠️ Способ оплаты С НАЛОГОВОЙ ГАЛОЧКОЙ

**Это самый важный пункт. Нельзя пропустить.**

Спроси:
> Привязан ли способ оплаты к рекламному аккаунту?
> И главное — поставил ли ты галочку «я плачу налоги сам в своей стране» с указанием БИН/ИНН?

Если способ оплаты не привязан:
- В Ads Manager → Payment Settings → Add Payment Method
- В KZ работают: Kaspi, Halyk Visa/Mastercard, PayPal
- Карты «Мир» (РФ) — не работают

Если оплата есть, но галочки нет — **скажи прямо**:
> ⚠️ Без этой галочки Facebook удерживает +12% НДС (в KZ) или +20% (в РФ) с каждого пополнения. За уже удержанное — возврата нет.
>
> Зайди: Payment Settings → Business Information → впиши БИН/ИНН → поставь галочку «My business is registered for VAT» (или похожую).
>
> Изменения вступят в силу со следующего пополнения.

Гайд: https://www.facebook.com/business/help/331979752372842

## Финал интервью

После прохождения всех 7 пунктов — выведи краткое резюме:

```
ИТОГ ПРОВЕРКИ
─────────────
✓ Личный FB-аккаунт
✓ Business Manager
✓ Page в BM
✓ Ad Account (валюта USD, часовой пояс Asia/Almaty)
○ Instagram — не подключён (не нужен — клиент не идёт в IG)
○ WhatsApp — не подключён (не нужен — клиент не идёт в WA)
✓ Способ оплаты + налоговая галочка БИН 220340004421

Готов к запуску рекламы. Можешь использовать команду:
  > Покажи мои рекламные аккаунты
```

Если есть пункты которые не пройдены:

```
ИТОГ ПРОВЕРКИ
─────────────
✓ Личный FB-аккаунт
✗ Business Manager — НЕ создан
... и т.д.

Перед первым запуском рекламы нужно завершить отмеченные ✗ пункты.
Когда сделаешь — попроси меня «проверь готовность» и пройдём ещё раз.
```

## Чего НЕ делать

- **Не пытайся создавать BM, Page, Ad Account через API** — Meta не выдаёт permissions на это, и попытки ведут к бану аккаунта
- **Не запрашивай данные карты** — никогда. Способ оплаты вводится только в защищённом интерфейсе Facebook самим пользователем
- **Не пропускай вопрос про налоговую галочку** — это самая дорогая ошибка для KZ/RU аудитории
- **Не считай чек-лист пройденным** если пользователь говорит «не помню» — попроси проверить и вернуться

## Связь с другими скиллами

- После прохождения чеклиста → пользователь зовёт `dashboard` чтобы увидеть свои аккаунты
- При создании первого аккаунта в системе → `account-onboarding` (заполняет `agent/config/ad_accounts.md` и брифы)
- Когда нужно создавать кампании → `campaign-manager`
